# The Slow House — Cafe & Artisan Space

> A modern, aesthetic, and fully responsive website for **The Slow House - Cafe** located in Shirur Park, Hubballi, Karnataka.

![The Slow House Cafe](https://images.unsplash.com/photo-1514432324607-a09d9b4aefdd?w=1200&auto=format&fit=crop&q=85)

---

## 🌟 Key Features

- **Luxury Aesthetic Design**: Warm espresso & honey-amber dark luxury palette with serif typography.
- **Fluid Responsiveness**: Seamless experience across mobile phones (320px+), tablets, and desktop PCs (1200px+).
- **Scroll-Driven Motion**: Smooth blur-to-focus entrance reveals, 3D card tilt effects, and real-time scroll progress tracking.
- **✨ "Match Your Mood" (Vibe Check)**: Interactive mood selector that suggests curated coffee + bite pairings.
- **Interactive Full Menu Explorer**: Filter by categories (*Specialty Coffee, Cold Brews, Artisan Bakery, Bites & Pizza, Desserts*) with real-time search & vegetarian filter.
- **Slide-out Cart & WhatsApp Ordering**: Real-time subtotal calculation, tax breakdown, Dine-in/Takeaway toggle, and instant one-click WhatsApp order generation.
- **Table Reservation System**: Interactive booking form with date, time slots, guest count, and seating preferences.
- **Google Maps & Location**: Verified address, live *Open Now* status badge, phone quick-dial, and directions link.
- **Moments Gallery & Lightbox**: Instagram-style aesthetic photo showcase with full-screen viewer.

## 🚀 Quick Start

Run a local server to view the website:

```bash
# Using Python
python3 -m http.server 8080

# Or using Node
npx serve .
```

Open `http://localhost:8080` in your web browser.
